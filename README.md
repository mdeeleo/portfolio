# Construction Company Portfolio

A modern one-page portfolio website template for a construction company (Summit Build Co.).

## Features

- Responsive hero section with call-to-action buttons
- Services and featured projects sections
- Company statistics and about section
- Contact form with client-side submission feedback
- Mobile-friendly navigation menu

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
